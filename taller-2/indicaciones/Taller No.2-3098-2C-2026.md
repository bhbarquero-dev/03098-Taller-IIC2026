# Taller No.2

**Objetivo:** Desarrollar la capa de presentación del sitio web de *StayBooker 360*, implementando su estructura visual, funcionalidades básicas del lado del cliente y validaciones correspondientes.

Para este taller se deberán aplicar los conocimientos adquiridos en los **capítulos 7, 8, 9, 10, 11, 12 y 13**, evidenciando cómo cada uno contribuye al desarrollo estructural y funcional del sitio web.

## Parte 1

Cada estudiante entregará un documento en formato PDF que incluya:

* Una explicación de la estructura general del sitio web, utilizando HTML5 semántico (header, sections, articles, footer, etc.).
* La propuesta visual de las hojas de estilo CSS, detallando los bloques que compondrán el diseño (cajas, menús, formularios, botones), los efectos básicos aplicados (*hover*, transiciones, etc.), los colores, la tipografía, y la disposición de los elementos (espaciado, márgenes, alineación), así como los aspectos responsivos para adaptarse a diferentes dispositivos.
* Una descripción de cómo se validarán los formularios, se generará interactividad y se gestionará la experiencia del usuario en el front-end.
* Explicación de cómo se prepararán las secciones del sitio para un uso real posterior con bases de datos y sesiones activas, tomando en cuenta futuras integraciones back-end.

**Nota importante:** No se permite el uso de plantillas o prediseños comerciales. El diseño debe ser original y creado por el estudiante.

## Parte 2

En este taller, el estudiante deberá aplicar las reglas de la cascada de estilos para modelar las páginas solicitadas en el Taller 1. Debe definir los estilos para cada etiqueta y para cada formulario, incluyendo aspectos como bordes, colores, grosor, esquinas, fuente, tamaño y color.

Se espera que se definan acciones para el menú de navegación, como *onmouseover* y *onmouseout*, así como para los botones de los formularios.

Además, se debe entregar un sitio web funcional, responsivo y validado, con un enfoque en la preparación para el uso de formularios que gestionen el acceso a bases de datos. La parte responsiva puede lograrse empleando hojas de estilo en un 100%, sin depender de *frameworks*.

El sitio web debe estar listo en términos de campos y objetos necesarios para la futura codificación. Será una especie de prototipo que luego se implementará mediante código *back-end*.

Es importante realizar las validaciones necesarias en todos los formularios en el lado del cliente, utilizando la mayor cantidad de etiquetas HTML5. Se debe permitir el envío de información de una página a otra mediante código cliente y mantener una sesión activa. En relación con la sesión activa, se requiere al menos la función y el manejo de variables, con la idea de agregar código *back-end*.posteriormente.

El envío de datos no implica procesamiento en una base de datos, sino que se realizará del lado del cliente. Por ejemplo, se espera manejar saludos de bienvenida, validar correos electrónicos y campos de

formularios, además de validar espacios vacíos, tipos de caracteres y extensiones. El sitio web debe ser funcional desde la perspectiva de la interfaz de usuario.

Además, es necesario coordinar una video reunión con el profesor para exponer el sitio web de acuerdo con los criterios establecidos. Durante esta presentación, se requerirá que cada estudiante comparta su pantalla y muestre su rostro. Se destinarán 10 minutos para la exposición de cada estudiante. La fecha y hora de la reunión serán programadas con antelación.

Es importante considerar que estas páginas aun no son completamente funcionales; ambos talleres se centran en el maquetado y diseño desde la perspectiva del usuario.

Se sugiere ver el siguiente video como referencia: <https://www.youtube.com/watch?v=dYvwO7Hf3tE>
